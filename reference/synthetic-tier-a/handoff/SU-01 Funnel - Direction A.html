SU-01 · DIR A · MOBILE LOGIC

The funnel is already vertical, so mobile is mostly a scale-down — no layout exception. The countable cell-row is the one thing to protect: at 360px the ten cells still fit one row at ~22px, so the 3-of-10 read never breaks.

Headline moves up. The "3 of 10" statement leads, then the funnel proves it. On desktop the statement sits beside; on mobile it stacks above.

Run B demotes from a side rail to a single stacked card after the terminus — still visually distinct (dashed accent border) so it reads as a parallel companion, not a funnel step.

Terminus stays the heaviest object — the glow and the largest numerals carry down to mobile so the payoff still lands last.

↘ Direction A · read & trade-offs

§ 1 · What this direction is best atThe countable gap

Direction A's whole bet is that a countable ratio beats a stated one. A hiring design leader doesn't take "3 of 10" on faith — here they can verify it in under a second by counting filled cells. The funnel silhouette earns the "research method" framing; the discrete throat earns the credibility. The terminus is deliberately the heaviest object so "3 shipped changes" is the last beat, not a quiet caption.

§ 2 · Run B placementParallel rail, not a fifth step

Run B sits as a second vertical track to the right with its own magnitude (1 persona, 53 fixes) and a merge arrow into Run A's backlog. It reads as a companion run executed in parallel — present at full weight, never subordinated into the main funnel's step sequence. If Run B deserves more prominence, Direction B (two-track) is the stronger frame.

§ 3 · Risks for the portWhere it can strain

  • Cell row at small widths. Ten cells must stay one row to keep the count legible. Below ~330px they'd need to drop to ~18px or wrap — wrapping kills the read. Hold a one-row minimum.
  • Bar-width honesty. The bar widths are tuned to read as a funnel, not to be a precise area chart. If Matt wants strict proportional encoding, 18 should be 50% of 36 and 10 should be ~28% — slightly narrower than sketched. Flag the choice: legibility vs. strict proportionality.
  • Glow on the terminus is the one ambient flourish; keep it static (no pulse) per the visual-grammar "single-fire / no looping" rule.
