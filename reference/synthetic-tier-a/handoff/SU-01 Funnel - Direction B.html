SU-01 · DIR B · MOBILE LOGIC

The two tracks stack rather than sit side-by-side. Run A condenses to its number chain (36 → 18 → 10); Run B keeps its own framed block directly below. A "both feed" junction replaces the curved merge.

The backlog is the pivot and stays full-width with all ten cells countable — protect the one-row cell layout down to 340px.

Run B never loses peer status — even stacked, its dashed-accent frame keeps it visually distinct from Run A and clearly parallel, not sequential.

Terminus stays the heaviest element so the "3 shipped" payoff still closes the sequence.

↘ Direction B · read & trade-offs

§ 1 · What this direction is best atRun B as a co-equal method

Where Direction A keeps Run B as a parallel rail, Direction B makes it a parallel column — a true second track that joins Run A at a shared backlog. If the case wants to argue that the methodology is two complementary runs (broad persona QA + deep design-systems audit), this composition carries that claim structurally. The merge is the thesis: different inputs, one prioritized output.

§ 2 · The costThe gap lands later

The trade-off is sequencing. In Direction A the 3-of-10 gap is the spine; here it resolves after the merge, one beat later. The piece spends its first half on "two methods converge" and its second half on "and three of them were blind spots." That's a richer story but a slightly slower punch. If the single most important thing is the gap, A is more direct; if the parallel-methods framing matters as much, B wins.

§ 3 · Risks for the portWhere it can strain

  • Equal-height columns. Run B's lane must stretch to match Run A's stack height for the merge to read flat. Built with a stretch grid; verify at content changes.
  • Merge curve honesty. The Bézier merge is decorative geometry, not data. Keep it subtle so it reads as a construction line, not a chart.
  • Backlog density. Ten cells + a +53 chip + legend is a lot in one bar; below ~480px the chip should drop under the cells, not beside them.

§ 4 · Recommendation between A and B

Lead with Direction A if the page's job is to make the gap undeniable fast — it's the cleaner single-idea artifact. Choose Direction B if Run B deserves equal billing and the "two parallel runs" framing is load-bearing for the methodology argument. They're not blends; pick the spine. A third, more typographic "ratio-only" direction can be sketched if neither composition is right.
