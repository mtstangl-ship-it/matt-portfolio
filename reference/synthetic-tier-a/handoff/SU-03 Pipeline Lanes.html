WHY IT READS AS A PIPELINE

  • Spine + gates. A continuous DEV→QA→UAT→PROD rail with PASS gates and a terminal SHIP — the CI/CD release shape, applied to portfolio review.
  • Advance, don't browse. Gates imply sequence and a stop condition; a grid would imply four independent boxes.

TWO PROMINENT LAYERS

  • Persona class as a chip (Archetype / Thought-leader / LinkedIn-modeled / Adversarial) — it matters as much as the environment.
  • Diagnostic question is the hero line; the decisive phrase (60 seconds, 300 portfolios…) is accented so it carries.

RUN B

  • Parallel rail beneath, dashed + tagged PARALLEL — a companion audit, explicitly not a fifth lane, folding into the backlog.

MOBILE (≤900PX)

SU-03 · MOBILE LOGIC

The pipeline rotates 90°. Lanes stack top-to-bottom; the spine becomes vertical; PASS gates become downward gate-ticks between lanes. The same DEV → QA → UAT → PROD → SHIP sequence, read by scrolling.

Questions stay the hero. Even at 360px the diagnostic question never drops below ~15px — it's the thing a reader should remember from each lane, so it never demotes to caption size.

Persona-class chips persist above each question; they're as load-bearing as the environment label and survive the collapse intact.

Run B trails as a distinct dashed block after SHIP — still visibly parallel to (not part of) the lane sequence.

↘ Pipeline Lanes · read & trade-offs

§ 1 · The metaphor earns its keepGates, not cells

The difference between this and the impact-vis 4-up grid is the gate. A gate says "advance only if you pass," which is exactly what staging a portfolio through DEV/QA/UAT/PROD means. The terminal SHIP gives the sequence a destination. Together they convert four parallel boxes into one directional process — the read the brief asked for.

§ 2 · Question as heroDiagnostics carry the lane

Each lane's diagnostic question is set at display scale with its decisive phrase accented — 60 seconds, Five practitioner worldviews, the specific person, 300 portfolios. These are the lines a reviewer remembers; sizing them as headlines (not captions) is the point. The persona-class chip above each anchors who is asking, which the brief flags as equally important to where.

§ 3 · Risks for the port

  • Lane height parity. Question lengths differ (PROD is longest); lanes are flex-stretched to equal height. Verify the shortest lane's note still pins to the bottom rule.
  • Gate width at mid-widths. 62px gates can crowd between ~820–980px; consider dropping the "PASS" label before rotating to vertical.
  • Run B prominence. A dashed rail reads as parallel, but if Matt feels it's under-weighted, it can gain a left node aligned to the spine to show the parallel start more literally.
