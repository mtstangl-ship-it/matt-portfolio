03 — Component specs

Five primitives do the whole page

A. Tab bar

Role
Top-level case switcher. Sticky on scroll. Three children only.
States
default · hover (bg shift) · selected (panel bg + 2px teal top bar + teal index label)
Anatomy
index (mono, teal when active) → name → client (mono, hidden < 720)
Persistence
localStorage['stangl-impact-tab']
Keyboard
arrow L/R switches, Home/End jumps, Enter activates

B. Hero metric

Role
One big number per tab. Always first after tab switch.
Anatomy
numeral (300 weight, clamp 56–132) → teal label (mono) → unit line (mono muted)
Emphasis
Numeric digits get em wrap and are teal; unit characters ($, %, M) stay ink.
Placement
Mobile: left-aligned, below role sentence. Desktop: right-aligned, sits opposite role sentence.

C. Tier ladder revenue

Role
Replaces the tile-grid. Three rows, each a strategic tier in a clear hierarchy.
Row anatomy
step label (T01 / T02 / T03) · name + description · lift %· progress bar · expandable service list
Bar semantics
Width = tier's share of total lift, not services count. Top tier is widest by design.
Accordion
Single-open. Expanded state persists until another row is opened.
Service chips
Three states: innovated (teal) · optimized (ink border) · refined (muted)

D. Before/after compare + handoff track operations

Compare
Two columns. Before (muted bar, full width) · After (teal bar, 69%). Delta row closes with −31% MTTR.
Handoff
Three circular nodes on a horizontal rail with arrow glyphs between. On mobile, rail becomes vertical; arrows hide.
Node ring
T1 teal ring to signal the resolve-early goal. T2/T3 muted.
SLA chip
Target per tier: <4h · <2d · <5d. Teal bolded numeral.

E. Geo anchor + city list healthcare

Map
Original illustrative outline of Georgia in SVG, filled --bg-2, stroked --line-2. Faint grid behind.
Markers
Teal filled dot with 1–2 concentric rings. Active city gets amplified ring opacity + dot.
Connectors
Thin teal-dim lines between all four cities form the delivery mesh. Decorative, not interactive.
City row
Hover/click links to marker. Number right-aligned (engagements count). Underline on hover.

05 — Interaction notes

For the build agent
N·01
Tabs persist. Active tab is written to localStorage['stangl-impact-tab'] on every switch, read on load. Invalid values fall back to revenue.
N·02
Breadcrumb mirrors the tab. CONSOLE / Impact / {Revenue | Operations | Healthcare}. The final crumb shifts to teal.
N·03
Tier accordion is single-open. Opening one tier collapses the others. Default state opens Tier 01 so first paint shows a populated drawer, never an empty ladder.
N·04
Map and list are linked. Hover/click on either surface highlights the matching pair. Active marker bumps ring opacity to .9; inactive dots dim to --teal-dim.
N·05
Mobile first. Layouts start single-column. Side metadata rail only appears ≥ 860. Handoff rail rotates to vertical < 720. Hero metric stacks under the role sentence.
N·06
Motion budget. One easing, one duration. No parallax, no shimmer, no particle grid. The background grid is static and masked.
N·07
No placeholder data. Every chip, node, and count is a real number from the briefing. If a value is missing, remove the element — don't pad.
N·08
Accessibility. Tabs use role="tab" + aria-selected. Panels use role="tabpanel". Every interactive element reaches focus via keyboard; focus ring is 1px teal, offset 2.
N·09
Reduced motion. All transitions collapse to 0 under prefers-reduced-motion.
N·10
Identity is never below the fold. "Matt Stangl · Product & Service Design Leader" shows in the top bar on desktop and inside the identity card on entry.

Acceptance criteria

  • AC·01On first load, Revenue tab is active, Tier 01 ladder row is expanded, identity block renders above the tab bar.
  • AC·02Each tab's first sentence names exactly what Matt did — not an outcome, not a team. Visible within the first screen on mobile.
  • AC·03No tile grids, no node diagrams, no placeholder squares anywhere in the tree.
  • AC·04Dark background + teal are the only chromatic colors. Neutrals share hue 220, accent shares hue 190.
  • AC·05At 375px wide, every tab scrolls cleanly with no horizontal overflow and no text smaller than 12px.
  • AC·06Map + city list stay in sync under hover and click on any input device.
